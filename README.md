# Panel de Control Táctico - DINASED 2026
Este repositorio contiene el código fuente para el dashboard interactivo de análisis espacial y demográfico de personas desaparecidas en Ecuador. 

Archivos principales:
- `app.py`: Código en Python/Streamlit del dashboard.
- `desaparecidos_limpio.csv`: Base de datos procesada (EDA aplicado).
- `requirements.txt`: Dependencias del proyecto.
